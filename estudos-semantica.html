HTML Semântico

O que é semântica?

Semântica em HTML é usar as tags certas para cada parte do conteúdo, dando significado estrutural à página — não apenas aparência. Isso ajuda leitores de tela, buscadores e a manutenção do código.

Principais tags semânticas

  • <header> — cabeçalho da página ou seção.
  • <nav> — bloco de navegação.
  • <main> — conteúdo principal.
  • <section> — seção temática.
  • <article> — conteúdo independente.
  • <aside> — conteúdo complementar.
  • <footer> — rodapé.

Antes x Depois

Errado (apenas visual):

<div class="header"> <div class="titulo">Anne Vitória</div> </div>

Correto (semântico):

<header> <h1>Anne Vitória</h1> </header>

Benefícios

  • Acessibilidade para leitores de tela.
  • Melhor SEO (buscadores entendem a estrutura).
  • Código mais limpo, legível e fácil de manter.
