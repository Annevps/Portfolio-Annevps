SEO — Search Engine Optimization

O que é SEO?

SEO é o conjunto de técnicas que ajudam um site a aparecer melhor nos resultados orgânicos dos mecanismos de busca (como o Google). Envolve otimizar conteúdo, estrutura, performance e autoridade.

Principais pilares

  • SEO On-page: títulos, meta description, headings, URLs amigáveis, conteúdo relevante.
  • SEO Técnico: performance, mobile-first, HTTPS, sitemap, robots.txt, dados estruturados.
  • SEO Off-page: backlinks de qualidade, autoridade de domínio, presença em redes.

Exemplo de meta tags

Tags bem escritas ajudam o buscador a entender a página:

<title>Anne Vitória | Portfólio</title> <meta name="description" content="Portfólio profissional de Anne Vitória..." /> <meta name="viewport" content="width=device-width, initial-scale=1.0" />

Boas práticas

  • Um único <h1> por página.
  • Hierarquia correta de headings (h1 → h2 → h3).
  • Imagens com alt descritivo.
  • Conteúdo original e útil para o usuário.
  • Boa performance (Core Web Vitals).
